## 🎮 Об игре

**Змея Сортировщик** — это аркадная 3D-игра, где вы управляете красной змеёй на почтовом складе.

По ленте транспортера едут посылки двух цветов:
- 🔴 **Красные** — бракованные, их нужно **выбивать** с ленты ударом.
- 🟢 **Зелёные** — правильные, их **нельзя трогать** (штраф −5 секунд).

На пути встречаются деревянные ящики — в них врезаться нельзя, змея отскакивает.

### 🎯 Цель
Набрать **15 очков** (выбить 15 красных посылок) за **3 минуты**.

### 🏆 Награда
За победу вы получаете **Красную змею** — уникальный скин, который можно отправить на общую Доску почёта.

## 🕹️ Управление

### На компьютере
| Клавиша | Действие |
|---------|----------|
| `←` / `→` | Поворот влево / вправо |
| `↑` | Ускорение |
| `↓` | Замедление / стоп |
| `Пробел` (удерживать) | Зарядка удара |
| `Пробел` (отпустить) | Удар (рывок) |

### На телефоне
Экранные кнопки внизу:
- `◀` `▶` — поворот
- `▲` `▼` — ускорение / замедление
- `⚡` (удерживать) — зарядка удара, отпустить — удар

---

## ⚙️ Механика

- **Заряд удара** — держите кнопку удара, чтобы накопить силу. Чем сильнее заряд, тем мощнее рывок.
- **Штраф за зелёную посылку** — минус 5 секунд.
- **Столкновение с ящиком** — отскок, потеря темпа.
- **Ограничение по времени** — 3 минуты.

## 🛠️ Технологии

- **Three.js r128** — 3D-рендеринг
- **WebGL** — аппаратное ускорение
- **Vanilla JS** — без фреймворков
- **CSS3** — glass-морфизм, адаптивная вёрстка
- **Web Speech API** — голосовые подсказки
- **Web Audio API** — процедурные звуки (без внешних файлов)
